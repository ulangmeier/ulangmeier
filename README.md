## 🚀 About Me

I’m a software engineer at **[Langmeier Software](https://www.langmeier-software.com)**, where I lead the development of professional-grade backup solutions trusted by businesses and individuals alike. My engineering philosophy centres on **reliability at scale** — building systems that handle real-world edge cases gracefully and recover automatically when things go wrong.

- 🔭 Currently shipping **Adaptive Multiscaling** for smarter, resource-aware backup jobs
- 🦀 Integrating **Rust** modules into production pipelines for zero-cost abstraction and memory safety
- 💾 Deep-diving into **HDD I/O optimisation** — scheduling, block alignment, and throughput profiling
- 🤝 Advocate of [Responsible Coding 2025](https://github.com/ulangmeier/responsible-coding-2025) — ethical, structured, AI-assisted development
- 🌱 Continuously learning: distributed systems, formal verification, and advanced compiler techniques
